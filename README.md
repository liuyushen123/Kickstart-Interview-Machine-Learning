## 🎯 Project Objectives
* **Theoretical Foundation:** Master the underlying mathematics and statistics of ML algorithms.
* **Practical Application:** Build scalable, efficient models from scratch and utilizing industry-standard libraries.
* **Systems Optimization:** Leverage my background in computer science to explore the systems-level execution of ML models, paying attention to algorithmic complexity and memory efficiency.
