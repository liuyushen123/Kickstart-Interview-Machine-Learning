# 🚀 Kickstart Interview: Machine Learning Masterclass

Welcome to my personal repository tracking my progress through the **Interview Kickstart Machine Learning Masterclass**. This repository serves as a centralized knowledge base containing my notes, code implementations, system design frameworks, and interview prep strategies for FAANG+ MLE roles.

## 🎯 Course Overview
This program is designed to cover the end-to-end interview loop for Machine Learning Engineer (MLE), Applied Scientist, and Data Scientist roles. The curriculum is broken down into four core phases: Data Structures & Algorithms, Scalable System Design, Advanced ML System Design, and Behavioral/Career Coaching.

---

## 🗂️ Course Curriculum & Progress Tracking

### 🧱 Module 1: Data Structures & Algorithms (5 Weeks)
*Focuses on the coding rounds, mastering algorithmic patterns, and complexity analysis.*
- [ ] **Week 1: Sorting** (Asymptotic analysis, Divide & Conquer, Merge/Quick/Heap Sort)
- [ ] **Week 2: Recursion** (Combinatorial enumeration, Backtracking, general templates)
- [ ] **Week 3: Trees** (BSTs, Hash Tables, BFS/DFS Coding Patterns, Tree Traversals)
- [ ] **Week 4: Graphs** (Adjacency models, BFS/DFS traversal, Graph modeling templates)
- [ ] **Week 5: Dynamic Programming** (Overlapping subproblems, Memoization, Tabulation)

### 🏗️ Module 2: Scalable System Design (3 Weeks)
*Focuses on general scalable software architecture.*
- [ ] **Week 1: Online Processing Systems** (Load balancing, Caching, Sharding, CAP Theorem. *Case studies: URL Shortener, Twitter, Uber*)
- [ ] **Week 2: Batch Processing Systems** (Distributed File Systems, Map-Reduce, External Sort-Merge. *Case studies: Search Engines, Typeahead*)
- [ ] **Week 3: Stream Processing Systems** (Real-time data ingestion. *Case studies: Netflix, Google Maps, Trending Topics*)

### 🤖 Module 3: Machine Learning Masterclass (5 Weeks)
*The core of the program: applying ML to scalable system design and production modeling.*
- [ ] **Week 1: Supervised Learning I** - Designing a Search Relevance System (*Ranking models, NDCG, Precision@K, L1/L2 Regularization*)
- [ ] **Week 2: Supervised Learning II** - Designing a Video Recommendation System (*Collaborative filtering, Matrix factorization, Cold start problem*)
- [ ] **Week 3: Unsupervised Learning** - Designing an Anomaly Detection System (*Airbnb fraud detection, K-Means, DBSCAN, t-SNE vs PCA*)
- [ ] **Week 4: Deep Learning I** - 3D Athlete Tracking (*YOLO object detection, Multi-camera setups, Keypoint extraction*)
- [ ] **Week 5: Deep Learning II** - Product Ranking & Summarization with GenAI (*Pointwise/Pairwise ranking, Generative AI for reviews, Real-time scaling*)

### 💼 Module 4: Career Coaching & Behavioral Prep (3 Weeks)
*Navigating the non-technical hurdles of tech interviews.*
- [ ] **Week 1:** Interview Strategy and Success Metrics
- [ ] **Week 2:** Behavioral Interview Prep (Past project deep-dives, "Whole Person" concept)
- [ ] **Week 3:** Offer Evaluation and Salary Negotiation
